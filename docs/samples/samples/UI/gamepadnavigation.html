Gamepad UI Navigation ​

VexUI supports gamepad/controller navigation automatically. When the input mode is set to UI or GameAndUI, players can navigate UI buttons using a gamepad.

How It Works ​

  • D-Pad or Left Analog Stick: Navigate between buttons
  • South Button (A on Xbox): Activate the focused button
  • Auto-focus: The first button is automatically focused when UI loads
  • Smart Navigation: Finds the closest button in the direction you pressed

Navigation Behavior ​

Navigation only works when InputMode is not set to Game:

InputModeUI GamepadMouse
Game❌❌
UI✅✅
GameAndUI✅✅

Basic Usage ​

Your existing UI JSON files work without any changes:

cpp
auto ui = GetComponent<UiComponent>().m_vexUI;
ui->load("Assets/ui/mainmenu.json");

// Setup button callbacks (works for both gamepad and mouse)
ui->setOnClick("play_button", []() {
    log("Play pressed!");
});

// Enable UI mode for gamepad navigation
GetEngine().setInputMode(vex::InputMode::UI);

That's it. Gamepad navigation is automatically enabled for all buttons.

Focus Callbacks ​

You can respond to focus changes using onFocusEnter and onFocusLost callbacks on buttons:

cpp
auto ui = GetComponent<UiComponent>().m_vexUI;
ui->load("Assets/ui/mainmenu.json");

// Change color when button gets focus
ui->getWidget("play_button")->onFocusEnter = [ui]() {
    ui->setColor("play_button", {1.0f, 1.0f, 0.0f, 1.0f}); // Yellow
};

// Revert color when button loses focus
ui->getWidget("play_button")->onFocusLost = [ui]() {
    ui->setColor("play_button", {1.0f, 0.9f, 0.75f, 1.0f}); // Default
};

Getting Focused Widget ​

Retrieve the currently focused widget with getFocusedWidget():

cpp
auto ui = GetComponent<UiComponent>().m_vexUI;

Widget* focused = ui->getFocusedWidget();
if (focused) {
    log("Focused widget ID: %s", focused->id.c_str());
}

Advanced: Custom Focus Management ​

Combine focus callbacks with styling for advanced effects:

cpp
auto ui = GetComponent<UiComponent>().m_vexUI;
ui->load("Assets/ui/mainmenu.json");

auto setupButtonFocus = [ui](const std::string& buttonId, glm::vec4 focusColor) {
    auto button = ui->getWidget(buttonId);
    if (!button) return;
    
    glm::vec4 defaultColor = button->style.color;
    
    button->onFocusEnter = [ui, buttonId, focusColor]() {
        ui->setColor(buttonId, focusColor);
        ui->setBorder(buttonId, 2.0f, focusColor);
    };
    
    button->onFocusLost = [ui, buttonId, defaultColor]() {
        ui->setColor(buttonId, defaultColor);
        ui->setBorder(buttonId, 0.0f, {0, 0, 0, 0});
    };
};

setupButtonFocus("play_button", {1.0f, 1.0f, 0.0f, 1.0f});
setupButtonFocus("options_button", {1.0f, 1.0f, 0.0f, 1.0f});
setupButtonFocus("quit_button", {1.0f, 1.0f, 0.0f, 1.0f});

Requirements ​

  • Button widgets must have unique id attributes
  • Buttons should be spaced apart for intuitive navigation
  • A gamepad must be connected before the engine starts
  • InputMode must be UI or GameAndUI for gamepad navigation
